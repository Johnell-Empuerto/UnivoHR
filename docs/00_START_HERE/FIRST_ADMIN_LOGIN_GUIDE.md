# First Admin Login Guide

## Purpose of This Guide

This guide teaches you how to log in to UnivoHR for the first time. Logging in is the first step before you can set up your company, add employees, configure attendance, process payroll, or use any other feature in the system.

## Who Should Use This Guide

- System Administrator
- HR Admin
- Client Admin

Anyone who received the default admin account from the implementation team should use this guide.

## When To Use This Guide

Use this guide when:

- The UnivoHR system has just been delivered to your company.
- You are logging in as the first admin user.
- You need to access the system for the first time to begin setup.

## Before You Start

Make sure you have the following ready:

| Item | Example |
|---|---|
| System website link / URL | `https://your-company-univohr-link.com` |
| Default admin username | `admin` |
| Default admin password | `admin123` |
| Internet or local network connection | Stable connection |
| A web browser | Google Chrome, Microsoft Edge, or Mozilla Firefox |

**Important:** The implementation team may change the default credentials before handing over the system. If you received different login details, use those instead.

---

## Step 1: Open the UnivoHR Login Page

1. Open your web browser (Chrome, Edge, or Firefox).
2. Click the address bar at the top of the browser window.
3. Type the UnivoHR system link provided by your implementation team.  
   **Example:** `https://your-company-univohr-link.com`
4. Press the **Enter** key on your keyboard.
5. Wait a few seconds for the login page to load.

The login page should appear with a clean form asking for your username and password.

---

## Step 2: Enter the Admin Username

1. Find the **Username** field on the login page. It is usually the first text box.
2. Click inside the Username field. A blinking cursor will appear.
3. Type the admin username.  
   **Example:** `admin`
4. Double-check that you typed it correctly. Usernames are case-sensitive, so use lowercase letters unless told otherwise.

---

## Step 3: Enter the Admin Password

1. Find the **Password** field below the Username field.
2. Click inside the Password field.
3. Type the admin password.  
   **Default example:** `admin123`
4. The characters you type will appear as dots or asterisks to protect your password. This is normal.
5. Check that **Caps Lock** is not turned on. If Caps Lock is on, the password will not match because passwords are case-sensitive.
6. If you make a mistake, use the backspace key to erase and retype.

---

## Step 4: Click the Login Button

1. Look for the **Login** button below the password field. It is usually a blue or dark-colored button.
2. Click the **Login** button once.
3. Wait for the system to verify your account. This usually takes one to three seconds.
4. **Do not click the Login button repeatedly** while waiting. Clicking multiple times may cause errors or temporarily lock your account.

---

## Step 5: Confirm Successful Login

After a successful login, you will see the **Dashboard** page. Look for these signs to confirm you are logged in:

- A **Dashboard** screen showing cards or overview sections with numbers and summaries.
- A **sidebar menu** on the left side of the screen with navigation options.
- Your **admin name** or profile area, usually at the top-right or bottom of the sidebar.
- The system is now ready for you to use.

If you see the Dashboard, you have successfully logged in.

---

## What Happens After Login

Now that you are logged in, you can begin setting up the system. The UnivoHR dashboard gives you an overview of your company's data. Since this is a fresh system with no data yet, the dashboard may show empty or zero values. This is expected.

**Your first recommended action after login is to change the default admin password.** The default password is not secure and should not be used during real company operations.

---

## If Login Fails

### Wrong Username or Password

- Recheck the spelling of both the username and password.
- Check that **Caps Lock** is off. Passwords are case-sensitive.
- Make sure you are using the correct credentials. If the implementation team gave you different login details, use those.

### Page Does Not Load

- Check your internet connection or local network.
- Confirm that you typed the correct system link in the browser address bar.
- Try refreshing the page by pressing **F5** or clicking the refresh button.
- If the page still does not load, contact your system support or the implementation team.

### Account Locked

- After several failed login attempts, the system may temporarily lock the account for security.
- Wait for about 15 minutes before trying again.
- If you still cannot log in after waiting, contact the system administrator or implementation team.

### Forgot Password

- If the login page has a **Forgot Password** link, you can use it to reset your password — but only if email settings (SMTP) have already been configured.
- If email is not yet configured, the Forgot Password option will not work. In that case, ask the implementation team or system administrator to reset your password manually.

---

## Important Security Reminder

- **Do not share the admin password** with anyone who does not need it.
- **Change the default admin password immediately** after your first login. The next guide explains how.
- **Use a strong password** that is at least 8 characters long and includes letters, numbers, and symbols.
- **Do not use the default password** (`admin123`) during real company operations. It is only for initial login.

---

## Common Mistakes

- **Typing the wrong system link.** Make sure you type the URL exactly as provided by the implementation team.
- **Using employee credentials instead of admin credentials.** The default `admin` account is for system setup. Employee accounts are created later.
- **Forgetting that passwords are case-sensitive.** `Admin123` is different from `admin123`.
- **Clicking the Login button many times** while waiting. Click once and be patient.
- **Not changing the default password after login.** This is a security risk. Change it right away.
