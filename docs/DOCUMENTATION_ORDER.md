## Recommendation: First Document to Write

**The first module documentation to write is:**
### First Admin Login Guide

**Reason:** The system is delivered with a single default admin account and empty tables. The admin cannot do anything until they log in. This guide is the prerequisite for every other document — no other setup step is possible without it.

**File path:** `docs/00_START_HERE/FIRST_ADMIN_LOGIN_GUIDE.md`

**What it should cover:**
- What this guide is for (first-time login to the UnivoHR system)
- Who uses this guide (the client admin who received the system)
- Prerequisites: system URL, admin username/password provided by the implementation team
- Where to open the browser and enter the URL
- What the login page looks like
- What fields to fill in (username, password)
- What happens after clicking Login
- What to do if login fails (caps lock, wrong credentials)
- What to do next: immediately change the default admin password
- Related guide: [Change Admin Password Guide ➜](../00_START_HERE/CHANGE_ADMIN_PASSWORD_GUIDE.md)
